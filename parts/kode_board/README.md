# Kode Dot virtual I²C board part

This WebAssembly part is loaded by ESP-EMU's official `CosimPump`. It models only the I²C devices needed to bring up the KodeOS display/input path:

- **TCA6408A** at `0x20`, on I²C0 GPIO5 (SCL) / GPIO4 (SDA). It models the four register banks, the active-low button inputs, touch interrupt bit, panel-power output and the expander's active-low IRQ on GPIO6.
- **CST820** at `0x15`, on the same bus. It reports the CST8xx-family ID expected by the pinned SDK and exposes a six-byte touch frame. Browser taps are injected as short single-finger events.

The screen pixels are **not** generated by this part. The pinned KodeOS/KGUI firmware renders into two RGB565 PSRAM framebuffers through the simulator-only headless display overlay. The KodeOS console screenshot command exports those actual pixels for the browser canvas.

This is not a complete hardware model: it does not implement the CO5300 MIPI-DSI panel, SD card, IMU, NFC/RFID, audio codec, haptics, IR or the separate ESP32-C5 radio. Unsupported devices remain unsupported rather than returning invented sensor data.
