# Version navigateur

Le site publié ici sera généré à partir du binaire WebAssembly du simulateur KGUI amont. Les fichiers compilés ne sont pas encore présents : ils seront ajoutés après validation de la chaîne Emscripten.

Ne pas remplacer le simulateur KGUI par une maquette dessinée en HTML : le but du projet est d'exécuter le vrai code KGUI/LVGL.
